# July English Speaking Lab

面向《公共英语1》课堂的校园英语口语自主练习网站。

学生先跟读四个校园场景的示范对话，再任选一个场景完成三轮模拟对话；系统提供句型提示、学习建议和任务型评分，并把对话文本与学生同意上传的录音保存到教师后台。

## 网站入口

- 学生统一入口：<https://1274526084-dot.github.io/july-speaking-lab/>
- 教师数据入口：<https://1274526084-dot.github.io/july-speaking-lab/teacher>

GitHub Pages 提供稳定入口并转到完整教学应用。录音上传、数据保存和教师身份验证继续由服务器端运行环境处理，因为这些功能无法只靠静态 GitHub Pages 完成。

## 主要功能

- 四个校园交际场景的示范音频与跟读文本
- 学生自主选择场景，按提示完成三轮对话
- 对话结束后获得分项评分与改进建议
- 经学生确认后上传练习录音、对话和评分
- 教师后台查看数据、逐轮回听录音并导出 CSV

## 隐私说明

仓库不保存学生提交数据、学生录音、教师邮箱或登录凭据。学生数据与录音保存在受控的服务器端数据库和对象存储中。
